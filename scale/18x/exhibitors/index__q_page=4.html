opsi
Silver Sponsor
http://www.opsi.org/

opsi is an open source client management system to manage heterogeneous environments. It enables the deployment and configuration from OS's and software on Windows and Linux computers. opsi is a powerful tool that will allow you to manage from a dozen clients, up to several thousands. Through the integrated inventory you get an overview of the hardware and software. This makes opsi the ideal tool for every system administrator. Opsi is deployed across all sectors in the fields of education, business and public administration.
